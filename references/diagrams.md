# 图解（内联 SVG）

好图解是这类演示质感的主要来源：线描、留白、一个强调色，看起来像编辑部画的示意图，而不是图表软件的默认输出。

## 先想清楚再画

1. 这张图回答什么问题？用一句话写下来，这句话通常就是这页的标题。
2. 只画回答这个问题需要的元素。其余全部删掉，包括"为了好看"的装饰。
3. 画的是真实机制：实际的组件、实际的数据流向、实际的数值。不画抽象的"齿轮 + 云 + 箭头"。

## 样式词汇（全部走 token，换主题自动跟随）

| 类                                | 外观                                                                                       |
| --------------------------------- | ------------------------------------------------------------------------------------------ |
| `.d-box`                          | 卡片底色 + 1.5px 墨线框；常用圆角 `rx="12"`–`"18"`                                         |
| `.d-box.ink` / `.tint` / `.hatch` | 墨色实心 / 强调色淡底 + 强调色描边 / 斜线填充（表示"被替换的/外部的/未知的"）              |
| `.d-inner`                        | 框内再套一圈细线（内缩 12px），立刻有"画框"的精致感                                        |
| `.d-line` / `.d-line.dash`        | 1.5px 墨线 / 虚线（辅助线、未来、可选）                                                    |
| `.d-acc`                          | 2.5px 强调色线：主路径、关键关系，**一张图只有一条主路径**                                 |
| `.d-pill`                         | 胶囊：指针、引用、分支名、标签（`rx` = 高度的一半），纸色底 + 墨线                         |
| `.d-fill-acc` / `.d-fill-ink`     | 实心点、小标记                                                                             |
| `.d-dim`                          | 尺寸标注：两端带小箭头的灰细线，旁边用 `.d-label` 写长度、耗时、容量（蓝图皮肤里尤其合适） |
| `.d-title`                        | 衬线 32px：框内名称                                                                        |
| `.d-text`                         | 无衬线 24px：说明                                                                          |
| `.d-label` / `.d-label.acc`       | 等宽 19px，字距大：编号、单位、坐标、小标签                                                |
| `.on-ink`                         | 墨色框里的反白文字                                                                         |

箭头：`marker-end="url(#arrow)"`（墨色）、`url(#arrow-acc)`（强调色）；`.d-dim` 自带两端小箭头，不用写 marker。皮肤会改笔触：terminal 和 blueprint 下圆角自动归零、线更细，画的时候不用管。斜线填充：`fill="url(#hatch)"` 或 `class="d-box hatch"`。这些都定义在 index.html 底部的全局 `<svg class="defs">` 里。

## 构图规则

- `viewBox` 按实际要放的区域设定比例。`split` 右栏约 900×640，整宽约 1680×520，封面右侧约 760×640。
- 网格对齐：坐标取 10 的倍数，同类元素等宽、等距。
- 文字不要压在线上，标签离图形 12–20px。SVG 文字的最终显示尺寸至少 18px：viewBox 被缩小显示时要相应放大字号。
- 线条数量少于 15 条，框少于 8 个。超过就拆成两步揭示或两页。
- 文字不要压在斜线填充（`.hatch`）上，几乎读不清：要标记"被替换/外部"的节点，用素框加一条短斜线标签，或只给框的一角上斜线。
- 尺寸标注：`<line class="d-dim" x1="100" y1="300" x2="500" y2="300"/>`，标签用 `.d-label` 放在线上方 12–20px 处（`<text class="d-label" x="300" y="284" text-anchor="middle">32k msg/s</text>`）。在 `.pen` 里箭头会等线描完才出现。
- 强调色只给"答案"：主路径、结论节点、关键数值。

## 动起来

- 整张图线描入场：在 `<svg>` 或 `<g>` 上加 `class="pen" data-in="0"`。描边先画；填色延后 0.5s 淡入；箭头（marker）等线画完才出现；文字和 `.fill` 元素在 0.9s 后淡入。虚线（`.dash`）没法描线，在 pen 里会改成淡入。
- 分步讲解：把图分成多个 `<g>`，各自写 `data-in`。或者一开始全部画出，再用 `data-state="lit@2"` 和 `dim@…` 逐个点亮。
- 位移动画：给 `<g>` 写一个状态类，在 custom.css 里用 `transform` 加 transition 实现。示例是 camera 页的 `.viewfinder.go`。SVG 元素的 `transform` 单位是 viewBox 坐标。

## 常用图式

- **管线**：从左到右排 3–5 个 `.d-box`，用 `.d-line` 加箭头连接，主路径用 `.d-acc`，每个框下方放一个 `.d-label` 编号。
- **对照**：左右两组相同结构，被替换的一侧用 `.hatch`，新方案一侧用 `.tint`。
- **层级 / 包含**：外层大框用 `.d-inner` 双线，内层小框横向排列。
- **循环**：3–4 个节点放在圆周上，用一条 `.d-acc` 弧线首尾相接，弧上标注循环名。
- **有向图 / 提交历史**：节点用等宽文字的胶囊或圆角框，横向排列表示时间，箭头指向"父"。指针用 `.d-pill` 加衬线名字，放在节点上方或下方，用短线连接。新增的节点放在 `<g data-in>` 里分步出现。
- **规模对比**：用面积表示数量。圆的半径必须按 √数值 计算，不要拍脑袋。
